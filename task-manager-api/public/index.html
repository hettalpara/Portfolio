Task Manager API Tester

Offline browser interface to test all REST API endpoints

GET

/tasks — Get All Tasks

Fetches every task currently stored in-memory.

GET

/tasks/:id — Get One Task

Fetches a single task by its ID. Returns 404 if not found, 400 if ID is invalid.

POST

/tasks — Create a Task

Creates a new task. Sends JSON body with title and completed status.

PUT

/tasks/:id — Update a Task

Updates an existing task's title and/or completed status. Returns 404 if not found.

DELETE

/tasks/:id — Delete a Task

Permanently removes a task by its ID. Returns 404 if not found.
